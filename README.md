# BuildSphere - Full-Stack System Architecture

A highly modular architecture demonstrating clean frontend, backend, and database separation.

## Tech Stack
*   **Frontend**: Vanilla HTML/JS, Tailwind CSS (via CDN), GSAP 3, SweetAlert2.
*   **Backend**: Node.js, Express.js, Multer (for file uploads).
*   **Database**: Local JSON Store (`data.json`) for data persistence.

## Local Setup
Follow these 3 steps to boot the application locally. Since the backend serves the frontend statically, only one terminal is required.

1.  **Clone the Repository**
    ```bash
    git clone <your-repo-url>
    cd buildsphere/BACKEND
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Start the Server**
    ```bash
    npm start
    ```
    The app will be available at `http://localhost:3000`.
